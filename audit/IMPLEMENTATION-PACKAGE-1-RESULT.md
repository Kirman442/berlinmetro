## Что изменено

| Пункт | Решение |
|---|---|
| 1.1 Идентичность и счётчики | Новый ключ станционного узла `s.node` (`src/lib/model.js`, `assignNodes`). Записи объединяются в узел, если совпадает wikidata или совпадает название при расстоянии ≤ 500 м (`NODE_RADIUS`), объединение транзитивное (union-find). Так к своему узлу присоединяются записи без wikidata (это вторые платформенные уровни U1-Nu/U3-Nu Nollendorfplatz, U9-Slu Schloßstraße, U7-Jhu Jungfernheide). Если записей больше, чем узлов, это видно во всплывающей подсказке у числа: «13 Bahnhöfe, 14 Bahnsteig-/Ebenen-Einträge». Константы не используются, всё считается по данным. |
| 1.2 Пустой профиль | `LineCard` получает признак `hidden`. Для скрытой линии карточка пишет «Linie U5 ist ausgeblendet.» с кнопкой «Linie U5 einblenden». Фраза «Im Jahr … noch nicht in Betrieb» показывается только если линия видна, но в этом году у неё нет открытых станций. |
| 1.3 Самые глубокие | В список попадают только подземные записи: `z < 0` и Lage содержит «Tunnel» (или Lage отсутствует, это исторический Richard-Wagner-Platz Kleinprofil). Einschnitt, Damm, Viadukt и Plan исключены. Если таких записей меньше 10, список короче. У каждой строки есть значок линии, значение со знаком в том же формате, что на карте (`−17 m`, `≈ −12 m` для оценок). В карточке станции знак теперь тот же: `−17 m (unter Straßenniveau)`, `≈` у оценок. Заголовок: «Tiefste Bahnhöfe (Tunnel)». «m max. Tiefe» в шапке считается тоже только по подземным записям. |
| 1.4 Восстановление | Все линии выключены: по центру «Keine Linien eingeblendet.» и кнопка «Alle anzeigen». Если выбранная станция исчезла, вместо молча пропавшей карточки показывается карточка-причина с действием: линия скрыта → «Einblenden»; ещё не открыта → «Zu JJJJ springen»; закрыта → «Zu JJJJ springen» (последний год работы); `map_from` → год появления. Всегда есть «Auswahl aufheben». Сам выбор сохраняется и возвращается, когда причина устранена. |

## Ограничения и вопросы данных

- Присоединение записей без wikidata по названию и расстоянию ≤ 500 м — эвристика для недостающего wikidata. Надёжнее проставить wikidata в `stations.geojson` у U1-Nu, U3-Nu, U9-Slu и U7-Jho/Jhu (Jungfernheide). Тогда эвристика станет не нужна.
- Подземность определяется по Lage из Википедии. Rathaus Schöneberg («Tunnel Plan», −5 м) считается подземным.
- 157 km по-прежнему сумма линейных участков с повторами общих участков U1/U3 (пакет 2.3).
- В карточке линии «Tiefe bis / Ø» пока считается по всем записям ниже нуля, включая Einschnitt (пакет 2.3).
